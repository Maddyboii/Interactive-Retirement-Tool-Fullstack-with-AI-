# Retire Wise Paths

Build a modern, attractive, fully functional, responsive web application called **RetireWise – Smart Retirement Planner**. The attached specification contains the complete requirements.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
